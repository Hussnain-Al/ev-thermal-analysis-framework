# References and Evidence

See [`SOURCE_PROVENANCE.md`](SOURCE_PROVENANCE.md) for the audited mapping from
the archived project files to each active MATLAB module.

Original component drawings and third-party documents remain in the owner's
source archive. They are identified by filename and hash for traceability but
are not redistributed by this public repository.

For a new study, record the following beside each imported component file:

- document title and revision;
- manufacturer or test source;
- test voltage, coolant and temperature conditions;
- units and conversion steps;
- whether values are measured, tabulated, digitized, reconstructed, or assumed;
- permitted interpolation range;
- known missing variables and validation action.

Method references used by the framework include:

- F. M. White, *Fluid Mechanics*, for Darcy-Weisbach, Colebrook, and fitting-loss methods.
- [U.S. EPA dynamometer drive schedules](https://www.epa.gov/vehicle-and-fuel-emissions-testing/dynamometer-drive-schedules) for standard time-speed scenario definitions.
- MathWorks EV thermal-management guidance for separating component behaviour, fluid circuits, operating scenarios, and supervisory controls.

Useful engineering standards depend on the intended market and verification scope. Examples include ISO 6469, ISO 19453, ISO 21782, IEC 62660, SAE J20, SAE J2464, SAE J2929, and UN Regulation No. 100. Listing a standard does not establish conformity.
